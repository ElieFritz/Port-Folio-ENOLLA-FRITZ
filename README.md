# Portfolio · Fritz ENOLLA

Site statique (HTML, CSS et JavaScript, sans build) : `index.html` et le dossier `assets/`.

- Bilingue FR / EN (bouton dans le menu).
- Animations inspirées d'EMANI : entrées en cascade, titres révélés mot par mot, images qui arrivent en vol au défilement, défilement fluide (Lenis).
- Logos des outils : voir `assets/tools/README.md`.

## Mettre en ligne

- **Vercel** : importer le dépôt, framework « Other », sans commande de build, dossier de sortie `.`.
- **GitHub Pages** : Settings > Pages > Deploy from a branch > `main` / root.
